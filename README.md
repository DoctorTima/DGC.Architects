# Журнал DGC.Architects: как разместить на GitHub Pages и Тильде

## Правила для новых статей

Все статьи журнала делаются по [STANDARD.md](STANDARD.md): слои «текст → кадры → живая 3D», уровни кода под старые iPhone, бюджет 3D-сцены, заглушки при сбое, проверки перед выпуском. Инструменты проверок лежат в `tools/` (`npm i` внутри `tools/` ставит esbuild и acorn для `compat_check.mjs`).

## Материалы журнала

- **REC. Вторая жизнь пятиэтажки** — `#rec-vtoraya-zhizn-pyatietazhki`
- **Долина. Что помещается на 26,6 м²?** — `#dolina`. Интерьер и визуализации — Владислав Изотов. Файлы статьи лежат в `assets/dolina`, стили и скрипт — `css/dolina.css` и `js/dolina.js`. Смета комплектации в публичную версию не входит: цены не согласованы к публикации.

Главная журнала — `#journal`, там обе статьи стоят рядом.

## Старые iPhone и встроенные браузеры (Instagram, Telegram и другие)

- **Облегчённый режим.** На iOS ниже 16, без WebGL 2, на слабых Android (до 2 ГБ памяти) и при экономии трафика 3D-сцены показываются заранее снятыми кадрами той же модели: REC — 61 кадр на всю прокрутку главы 05 (`assets/frames/rec-story`), «Долина» — кадр на каждый шаг (`assets/dolina/keys`). Кнопка «Включить 3D-модель» запускает живую модель по желанию читателя.
- **Пока живая модель загружается**, кадры показываются всем, затем плавно сменяются моделью. Если модель не запустилась, кадры остаются.
- **Встроенные браузеры на iPhone** не пишут «Safari» в своём User-Agent, и загрузчик three.js выбирал для них сломанный до iOS 17 способ загрузки текстур. В `js/viewer/vendor/GLTFLoader.js` и в просмотрщике «Долины» это исправлено (помечено `DGC: in-app`).
- **Анимация Blender** (глава 06): если видео не запускается внутри страницы, та же анимация идёт кадрами из `assets/frames/rec-parts`.
- **CSS:** у всех `svh`/`dvh` есть запасной `vh`, у `inset` — `top/right/bottom/left`, у `aspect-ratio` и контейнерных единиц — запасные размеры. Если скрипт журнала не запустился за 8 секунд, страница показывается целиком как обычный текст.

В репозитории две части:

- корень репозитория — сам сайт: страница, стили, скрипты, шрифты, картинки, видео и 3D-модель. Всего 114 файлов, около 72 МБ. Сайт полностью самостоятельный и ничего не берёт с других серверов.
- `tilda/tilda-code.html` — код для блока T123 на Тильде. Он показывает журнал во весь экран.

Тильда не умеет хранить сайт из сотни файлов, поэтому схема такая: файлы лежат на GitHub Pages (бесплатно), а Тильда показывает их на своей странице.

## 1. GitHub Pages

1. На github.com создайте новый репозиторий с именем `rec-journal`. Тип — **Public**, потому что Pages бесплатно работает только для публичных репозиториев.
2. Загрузите в корень репозитория **содержимое** папки `rec-journal`: файлы `index.html`, `.nojekyll` и папки `assets`, `css`, `js`, `models`. Саму папку `rec-journal` загружать не нужно. Через сайт это делается так: **Add file → Upload files**.
   - За один раз сайт принимает до 100 файлов, поэтому загрузите в два захода: сначала папку `models`, потом всё остальное.
   - Структура папок должна сохраниться. Удобнее всего перетаскивать папки с компьютера.
3. Откройте **Settings → Pages**. В разделе **Source** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://doctortima.github.io/DGC.Architects/`.

Этот адрес уже можно открывать и отправлять. Если нужен свой домен, например `journal.dgcarh.com`, укажите его в **Settings → Pages → Custom domain** и добавьте у регистратора CNAME-запись на `doctortima.github.io`.

## 2. Тильда

1. Создайте отдельную страницу, например с адресом `/rec`.
2. В **Настройках страницы** отключите общую шапку и подвал (Header/Footer → «Не показывать»), чтобы журнал занял весь экран.
3. Добавьте блок **T123 «HTML-код»** и вставьте в него весь текст из `tilda/tilda-code.html`.
4. В строке `src="https://doctortima.github.io/DGC.Architects/"` замените адрес на свой из шага 1.4.
5. Опубликуйте страницу. В редакторе Тильды HTML-код не выполняется, поэтому проверяйте уже опубликованную страницу.

Ссылки на главу тоже работают: `ваш-сайт.ru/rec#history` откроет журнал сразу на главе 01.

## Что уже сделано для корректной работы

- **Масштабирование.** Страница запрещает приближение и сдвиг вбок на всех устройствах, в том числе на iPhone и iPad. 3D-модель при этом сохраняет своё приближение двумя пальцами. Код для Тильды запрещает приближение и на самой странице Тильды.
- **Внешние ссылки.** Ссылки на источники открываются в новой вкладке: внутри рамки Тильды многие сайты не открылись бы.
- **Пути.** Все пути внутри сайта относительные, поэтому сайт работает в любой папке и на любом домене.
- **3D-модель** хранится в текстовых частях `models/*.txt` и собирается в браузере. Так модель одинаково работает на любом хостинге.

## Вес

- **Первый экран.** Сразу грузится около 1 МБ.
- **3D-модель.** Основная часть, около 28 МБ, подгружается, только когда читатель доходит до главы 05.
- **Полная модель.** Ещё около 36 МБ загружается только по кнопке «Открыть 3D-модель».
- **Лимиты.** Ограничения GitHub Pages (1 ГБ на сайт, 100 ГБ трафика в месяц) для такого журнала с запасом.
